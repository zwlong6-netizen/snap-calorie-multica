# 产品需求规格说明书（PRD）

## 项目概述
**项目名称**：AI卡路里拍照识别与摄入管理
**目标**：通过拍照快速识别食物并估算卡路里，自动统计每日摄入量，帮助用户实现健康饮食管理。

## 背景与痛点
- 用户希望无需手动输入食物信息，通过拍照即可获取热量及营养成分。
- 需要提供每日热量累计、目标差额、历史记录等功能，以支持饮食监控与目标达成。

## 核心需求
### 1. 基础功能
- **食物图片识别**：上传或拍摄食物图片，返回卡路里、蛋白质、脂肪、碳水等主要营养成分。
- **每日摄入统计**：自动累计当天摄入的卡路里，展示与用户设定的日目标差额。
- **历史记录**：按日期/餐次（早餐、午餐、晚餐、加餐）保存摄入记录，提供时间轴视图。

### 2. 扩展功能（产品深度发掘）
- **智能饮食建议**：基于摄入数据给出营养平衡、盐脂摄入警告等提示。
- **个性化卡路里目标**：依据身高、体重、目标（减脂/增肌/维持）自动计算 TDEE 并推荐日摄入上限。
- **手动修正与食物库搜索**：在识别误差或称重不准时，支持手动编辑或从食物库多选搜索。
- **饮水、运动互抵**：记录饮水打卡；支持手动录入运动消耗，抵扣每日热量总量。

## 非功能需求
- **性能**：图片识别响应时间 ≤ 3 秒（在移动端网络条件下）。
- **数据安全**：所有用户数据加密存储，符合 GDPR/本地法规。 
- **可用性**：UI 简洁，操作流程不超过 3 步。

## 自测要点
- 通过多种食物图片，验证识别精度 ≥ 85%。
- 每日累计功能在不同时间段多次记录数据后仍保持正确。
- 手动编辑后数据立即同步至历史记录。
